**🌐 Shea Daily - Website Project Documentation**

Dokumentasi resmi untuk pengembangan proyek website e-commerce / katalog produk Shea Daily. Repository ini memuat informasi umum proyek, struktur teknis, serta tautan ke dokumen penting manajemen proyek dan aset media.

**📌 Deskripsi Proyek**

Shea Daily adalah platform website yang dirancang khusus untuk mempermudah pelanggan dalam mengeksplorasi, memilih, dan membeli produk hijab serta modest fashion harian. Proyek ini bertujuan menghadirkan pengalaman berbelanja yang responsif, modern, dan nyaman bagi pengguna.
